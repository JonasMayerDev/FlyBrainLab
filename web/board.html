How to read this page

  • Recorded, not live. Every post is an event of a real Omnigent research session (runs/<run_id>/record.jsonl), exported with python3 -m flylab.board export. Mock pipeline tests are excluded.
  • Stimuli from research. Each behaviour lists the published activation / silencing experiments (DOI) the lab can replay in silico. A match is a comparison with the paper, not a replication in a real fly.
  • Evidence levels are kept apart. "Body" means an independent body run agreed and the movement verifier did not object. "Brain / adapter" means the match is a brain read-out or follows from the hand-designed bridge by construction.
  • Carried forward chips show which earlier results a round's discussion explicitly named. A round that names none is shown as such.
  • Agent hypotheses are labelled agent-generated; none is confirmed in the wet lab.
